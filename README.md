# Bal Qamyr — сайт

Статический сайт: HTML, CSS и JavaScript без сборки и зависимостей.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все содержимое этой папки (index.html должен лежать в корне).
2. Откройте Settings → Pages.
3. В Source выберите «Deploy from a branch», ветку `main`, папку `/ (root)` и нажмите Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Что где лежит

- `index.html` — главная
- `catalog.html` — ассортимент с фильтрами и карточками
- `menu.html` — меню кафе с ценами (блюда, описания и цены правятся в `js/main.js`, в списке `MENU`; фото блюд лежат в `assets/img/menu`)
- `contacts.html` — как нас найти
- `css/style.css` — оформление и анимации
- `js/main.js` — язык RU/KZ, меню, каталог. Товары, описания и составы правятся в начале файла, в списке `PRODUCTS`.
- `assets/img` — изображения, `assets/fonts` — шрифты

## Заказ в WhatsApp

На странице меню гость собирает корзину и отправляет заказ в WhatsApp. Номер кафе задается в `js/main.js`, в строке `var WHATSAPP = "";` — только цифры с кодом страны, например `"77011234567"`. Пока номер пустой, WhatsApp попросит гостя выбрать чат вручную.

## Перед передачей владельцу

- Заменить изображения в `assets/img` на оригиналы (сейчас они вырезаны из скриншотов Instagram).
- Уточнить у владельца: время открытия, телефон или WhatsApp, цены.
- Удалить пометку «Концепт сайта…» в подвале всех трех страниц и строку `<meta name="robots" content="noindex">` в `<head>`. Обе помечены комментарием «ДЕМО».
